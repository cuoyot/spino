Tot el que necessites per practicar

Lectura a primera vista sense fi

Exercicis nous cada vegada en l’escala que triïs, amb una mà o amb totes dues. Amb dues mans, el baix manté un patró i la melodia segueix les notes de l’acord.

Escalfament Hanon

Cada sessió de piano comença amb un exercici d’El pianista virtuós, amb una guia visual de les mans i una demostració animada.

Amb teclat MIDI

Connecta’l per USB o Bluetooth: SPino comprova cada nota, també els acords. Fes servir els pedals per passar pàgina.

Al teu nivell

Tria el teu nivell de pianista i cada pràctica ajusta el ritme i el registre. La mà esquerra avança al seu propi ritme.

Planifica i repassa

Avui, calendari setmanal, rutines, recordatoris i historial amb notes i valoració de cada sessió.

Les teves partitures

Biblioteca de domini públic, els teus PDF amb anotacions i lectura per parts en horitzontal.
