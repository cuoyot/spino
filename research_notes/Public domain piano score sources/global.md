# Global public score repositories and difficulty resources

Research date: 2026-10-21. Scope: Australia, New Zealand, Japan and academic machine-readable piano resources. Discovery only: no files added to the application. Evidence quality matters: an accessible download is not a worldwide redistribution licence.

## Which repositories are useful for SPino?

### Takeaway
Prioritize Australia's National Library for historical piano PDF discovery, followed by Japan's National Diet Library for a curated Japanese expansion. New Zealand is useful for national repertoire but the reviewed collection is less immediately focused on solo piano. Academic XML datasets offer structure, but the strongest reviewed difficulty dataset is restricted.

### Cited Findings
- **National Library of Australia / Trove — high priority.** NLA preserves over 300,000 scores; its Brady collection includes nineteenth/early twentieth century piano music. Digitised item viewers expose PDF, JPEG ZIP and TIFF choices, stable `nla.obj` identifiers, creators and publication data. No MusicXML offering was established. [Collection](https://www.library.gov.au/discover/what-we-collect/music), [example viewer with download controls](https://nla.gov.au/nla.obj-171485200).
- NLA's institutional guidance separates original musical work rights (including arrangers, editors, lyricists and artwork) from Australian published-edition protection. Publishing requires declaring intention to the Library, clearance where needed, and a citation naming creator, Library and collection number. Its catalogue's out-of-copyright assessment can be wrong where underlying data is incomplete. This is not a blanket international reuse licence. [Music rights](https://www.library.gov.au/services/copyright-library-collections/rights-and-music-collection), [item-level caveat](https://catalogue.nla.gov.au/catalog/1430815).
- Trove's official v3 release documentation supports machine-readable XML queries, metadata facets, collection/provider filtering and API keys. This enables discovery pipelines; API metadata access does not license score images. No NLA score IIIF endpoint was verified in this pass. [Official API v3 specification](https://trove.nla.gov.au/sites/default/files/attachments/2023-07/Introducing%20Trove%20API%20v3%20-%20Release%203%20updated.pdf).
- **National Diet Library, Japan — medium priority.** NDL separates openly viewable content from transmission-service and on-site content; the Japan-resident transmission service is not public global access. Open access can mean expired copyright OR permission, requiring the exact item's basis to be recorded. [Online service description](https://www.ndl.go.jp/en/use/service).
- NDL permits reuse of qualifying expired-copyright material and requests acknowledgement such as “From the National Diet Library Digital Collections”; third-party protected material requires rights-holder permission. “Available without login” alone must not be treated as a free licence. [Reuse guidance](https://www.ndl.go.jp/en/help/utilizing), [official service pamphlet](https://www.ndl.go.jp/file/dlib/NDLdigitalcollections_eng.pdf).
- NDL offers stable PID/DOI identifiers, metadata APIs and IIIF for relevant expired-copyright digitised books/rare books. Its documented manifest template is `https://www.dl.ndl.go.jp/api/iiif/{PID}/manifest.json`, exposing attribution, licence reference and bibliographic metadata. No specific eligible solo-piano item's PDF was validated here. [URI policy](https://www.ndl.go.jp/dlib/standards/lod/uri), [IIIF specification](https://dl.ndl.go.jp/static/files/IIIF_interface_En.pdf), [APIs](https://www.ndl.go.jp/en/use/api).
- **National Library of New Zealand / Alexander Turnbull — exploratory priority.** Its music collection reports approximately 8,500 scores/sheet-music items (2020), including piano music and nearly 150 digitised WWI patriotic scores. Many are songs rather than solo piano. Users remain responsible for third-party copyright and permissions. No bulk solo-piano PDF feed, XML feed or reusable grade field was verified. [Music collection](https://natlib.govt.nz/a-z/new-zealand-music-sound-audio-visual-collection), [copyright policy](https://natlib.govt.nz/collections/types-of-items/about-this-site/copyright-and-privacy), [reuse policies](https://natlib.govt.nz/about-us/policies-and-plans/accessing-and-using-collections).
- **University of Sydney / Australharmony — useful scholarly discovery layer.** The Boulanger biographical page points to an institutional PDF of the 1856 *Caprice sur Norma*. However, no explicit worldwide redistribution licence for that exact PDF was located. Sydney's music guidance warns that some digitised score access depends on external subscription/licence arrangements. Therefore use it as provenance and discovery, pending exact file clearance. [Boulanger research](https://www.sydney.edu.au/paradisec/australharmony/boulanger-edward.php), [institutional score guidance](https://www.library.sydney.edu.au/browse/music).
- **ASAP academic dataset — structured but restricted.** The maintainer distributes piano MusicXML/MIDI plus key, metre and beat annotations and title/composer metadata; the README contains conflicting totals (222 versus 236 scores), so do not assert a single verified collection size. The dataset licence is CC BY-NC-SA 4.0, requiring attribution and limiting commercial reuse. No difficulty grades are claimed. [Dataset and citation](https://github.com/fosfrancesco/asap-dataset), [licence](https://github.com/fosfrancesco/asap-dataset/blob/master/LICENSE.md).
- **CIPI (UPF Barcelona / Sogang University Seoul) — research only, not an unrestricted content source.** Its Zenodo record identifies Henle-derived difficulty labels matched to public-domain MusicXML and reviewed by an expert pianist. The actual files are restricted; access requires academic affiliation/research justification and use is limited to non-profit/academic research. [Authoritative access conditions](https://zenodo.org/records/8037327).
- **64-score difficulty-annotated derivative — do not accept the licence headline as sufficient.** The repository claims CC BY 4.0 for reconstructed XML but requires CIPI `scores.zip`, provides patches rather than original scores, and still has placeholder paper/author/DOI fields. Its claim does not remove upstream restrictions or establish a licence to Henle's underlying database. [Maintainer README](https://github.com/cperezs/piano-difficulty-dataset).

### Inferences
- For Spain, a local Australia/Japan expired-copyright flag is evidence for a review, not sufficient worldwide clearance: Spain's BNE states the usual seventy-year term and an eighty-year term for authors deceased before 7 December 1987. Every arrangement/editor/image contributor and edition needs identification. [BNE explanation](https://www.bne.es/es/servicios/autores-dominio-publico).
- SPino should store source item ID, exact edition, composer/arranger/editor, file URL, rights statement URL/text, jurisdiction checked, attribution and verification date for each candidate. A public preview can use the same cleared score pages, avoiding unlicensed promotional thumbnails.

### Gaps
- No worldwide rights assurance is available from these institution pages. No specific New Zealand or Japanese solo-piano file reached candidate-ready evidence in this bounded pass.
- NLA web-view fetches were intermittently blocked/cache-missed; direct HTTP verification from the shell failed because host DNS/network was unavailable. Candidate status below explicitly distinguishes indexed evidence from byte-verified files.

## Can SPino show trustworthy difficulty ratings?

### Takeaway
Yes: display a documented external reference only when the work, movement, arrangement and source are matched; otherwise show “Difficulty not assessed”. Previews of the actual cleared score are more reliable than inferring difficulty from a title. Machine estimates need a separate explicit label.

### Cited Findings
- Henle publishes a nine-level piano scale, grouped 1–3 easy, 4–6 medium, 7–9 difficult. Its explanation emphasizes subjective musical/technical judgment, worst passages and performance preparation. This is not a universal equivalent to examination grades. [Henle primary guidance](https://www.henle.de/us/Levels-of-Difficulty/).
- Henle's catalogue filters apply to its Urtext editions and individual contents, enabling work/movement reference checks. An unrelated simplified arrangement must not inherit the original work's grade. No open bulk-reuse licence/API for the rating database was found. [Henle catalogue](https://www.henle.de/Piano-solo/).
- ABRSM publishes official repertoire lists tied to syllabus periods and grades, including edition/publisher details. A truthful label can say “ABRSM Grade X, syllabus YYYY–YYYY” for an exact match. The institution also publishes corrections and has already announced 2027–2028 material, so retain the syllabus version and check corrections. [Syllabuses](https://www.abrsm.org/en-gb/syllabuses), [official 2025–2026 piano PDF](https://www.abrsm.org/sites/default/files/2024-06/Piano%202025%20%26%202026%20Prac%20syllabus%2020240524_access.pdf), [2027–2028 launch](https://teacherhub.abrsm.org/mod/page/view.php?id=2009).
- CIPI's labels are sourced from Henle and reviewed by an expert; its prediction model achieves only 39.5% balanced accuracy across nine levels. A model output is not a Henle rating. [Author's model and paper description](https://github.com/pramoneda/difficulty-prediction-cipi).

### Inferences
- Recommended data shape: `system`, `value`, `sourceUrl`, `workId`, `movement`, `editionOrArrangement`, `syllabusYears`, `verifiedAt`, `method` (published reference / musician review / automated estimate). Never synthesize a Henle or ABRSM label from an automatic estimate.
- In the UI use a compact score preview with page count, instrumentation and attribution; show difficulty only when sourced. “Easy” in a historical item's title is useful searchable metadata but belongs in its description, with its provenance.
- Display selected factual external references with links; do not bulk scrape/repackage Henle or ABRSM databases without checking permission. None of the reviewed national-library metadata establishes a reusable standardized difficulty field.

### Gaps
- No public archive reviewed supplies a clearly licensed, edition-specific difficulty dataset suitable for unrestricted application redistribution.
- Exact Henle/ABRSM facts can be researched individually, but permission for systematic database extraction was not established.
