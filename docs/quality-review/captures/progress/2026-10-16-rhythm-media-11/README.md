# Clickable month heading and period navigation

Responsive Chromium browser evidence, 2026-10-16. Disposable synthetic notebooks/recordings; not native-device or owner visual acceptance.

Multimedia opens weekly. The month/year heading expands to month and collapses back to week; no separate Week/Month or filter controls remain. Arrows navigate the displayed period, preserving the day/week anchor. The list follows that period. Empty dates stay neutral and recording dates retain separate colored audio/video rows.

`metadata.json` records source/build hashes and 60 frames across light/dark, phone/tablet orientations and 320 px. The production build, three browser regressions (rhythm navigation, capture/playback and duration) and four arithmetic/locale checks pass. Assertions cover heading expanded state/focus, week/month navigation and lists, absent filters, color/containment and retained notebook/recording identities. The final locale assertion was updated separately to the heading control. Earlier runs are preserved. No APK/version/publication.
