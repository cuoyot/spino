# Automatic archive status — responsive browser, 26 October 2026

The real storage controller runs against a disposable notebook, a synthetic Drive transport and a staged document writer. The main row displays last backup and destination when enabled. Four layouts capture Preparing ZIP, Saving, and the refreshed saved date. The progress bar is indeterminate until an actual file/byte count exists; no invented completion percentage is used. The previous backup remains visible during preparation/save. Unit checks cover count-based progress and disabled/error states.

The browser test also verifies the JSON import entry and explicit no-multimedia export copy, one folder-picker Cancel, Use this folder, and return to the existing settings draft. Physical Google Drive/document-provider acceptance is separate. Native Android instrumentation verifies real local file bytes and seven-archive retention. This revision is unreleased and remains open for owner visual feedback.
