# Drive notebook recovery — responsive browser evidence

Date: 2026-10-22. App: 6.1.2-beta.1 (87). Disposable synthetic Google Drive and IndexedDB only; no personal account or notebook.

Four portrait/landscape captures compare same-name notebooks: one saved practice of 127 minutes and a 240-minute target against zero sessions and a 90-minute target. The tested flow selects explicitly, reviews the overlapping target, adopts the saved practice, renames the descriptor while preserving identity, displays the exact-file QR and opens the channel-aware local export dialog. Five Drive browser regressions pass. Earlier dated runs are retained; run 05 verifies the final implementation, including preventing a QR-triggered reload.

These are responsive browser captures, not native-device acceptance. Native replacement installation and storage retention are recorded separately. Owner visual acceptance and real two-device Drive recovery remain open.
