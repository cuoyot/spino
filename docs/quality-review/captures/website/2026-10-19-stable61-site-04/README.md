# Stable 6.1.0 website imagery

Current production web build, captured on 19 October 2026 using disposable synthetic notebooks and generated audio. English, Spanish and Catalan phone portraits, tablet landscapes and phone landscapes; Catalan also includes a tablet portrait. Prior runs remain intact.

The images cover Today, routines, repertoire, quick practice/results, practice-time charts and filters, multimedia, Calendar and reading. `capture.json` records frame hashes and the build index hash. These are responsive-browser captures, not native-device acceptance. Source provenance is in `docs/releases/6.1.0-source-hashes.json`.
