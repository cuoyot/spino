# Compact floating score controls

Responsive-browser evidence with synthetic scores, separate from native-device acceptance. 46 frames cover PDF and MusicXML. See [verification](verification.json) for source/build hashes, checks and [synthetic inputs](fixture.json).

Double-tap the six-dot grip to show only the grip and clock; repeat to restore. Drag still moves the widget, keyboard Enter/Space toggles, and the expanded bar has 10 px less vertical space. At 320 px the grip retains a 44 px target and other icon buttons use 36 × 44 px targets to keep one row. Earlier attempts 01–06 are superseded debugging evidence.
