# SPino 6.1.4-beta.6 (97) — MIDI timing

Preserve Android MIDI nanosecond timestamps across the bridge and Web MIDI event timestamps. Sort events before millisecond-resolution export. Render piano audio offline in 20-second segments and play one buffer, removing UI timers from note scheduling. Normalize only peaks above 0.95 to avoid clipping dense chords. Retain first-note arming.

Input/export and rendered-PCM timing regressions include delayed delivery, UI stalls and segment boundaries. Physical keyboard and acoustic output acceptance remain pending. Existing distorted input timestamps cannot be reconstructed. Website beta delivery only.
