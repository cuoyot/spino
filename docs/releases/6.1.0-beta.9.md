# SPino 6.1.0-beta.9 (62)

## Release notes

Fixes the Google Drive transfer check reporting “Google Drive permission was not granted” even after successful consent. The Android bridge now checks the granted scope URI string returned by Google correctly.

Update both devices, open Profile → Google Drive transfer check, and connect the same Google account. Upload the synthetic recording on one device, then find, download, verify and play it on the other. While OAuth remains in testing, the selected accounts must be registered as Google test users. Personal recording synchronization is not enabled.

## Validation and delivery

Three regression tests use actual Google SDK result objects, covering valid grants, absent/different scopes and missing/empty access tokens. Ten transfer protocol tests pass. Final-version packaging, replacement installation, Profile navigation, notebook retention and foreground are verified separately from real Google consent and physical two-device transfer, which remain owner acceptance tests.
