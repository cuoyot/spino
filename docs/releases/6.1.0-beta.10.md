# SPino 6.1.0-beta.10 (63)

## Release notes

Android beta now connects notebook synchronization directly to your own Google Drive account. Open Profile → Backup & sync → Connect → Connect with Google. Use the current notebook in Drive on the first device, then connect the same account and choose that notebook on the second. Existing file-provider connections offer Move this connection to Google Drive in Manage; their previous files are kept. Moving both devices preserves the notebook identity and combines independent edits.

Your notebook remains saved locally. Practice offline, continue locally after a connection failure, and export or restore JSON copies from the same screen. The local recovery copy remains available after disconnecting. Drive sync includes practice history, repertoire, plans, scores, annotations and shared practice preferences. Theme and network preferences remain on each device; MIDI and notification permissions remain local. Personal recordings are not uploaded by notebook synchronization.

Updates run while SPino is open. Incoming changes wait until practice and editing finish, and overlapping edits require review. Reconnect renews Google permission for the same account. The earlier synthetic recording check remains separate. Existing file-provider and iOS connections remain available.

## Validation and delivery

Synthetic protocol and browser checks cover two-device discovery and merging, notebook/PDF/annotation identity, conditional-write contention, interrupted creation recovery, account isolation, permission renewal, offline pause/restart, and local JSON options. Android package, signing certificate, replacement installation and retained notebook data are verified separately. The owner has accepted the beta9 synthetic transfer on both devices; migration and real notebook synchronization through the new API remain physical-device acceptance tests for beta10.
