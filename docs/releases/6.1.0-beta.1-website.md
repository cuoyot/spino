# Beta 6.1 website refresh

Requested after the first 6.1 beta was published on October 15, 2026. The Android artifact and beta release tag remain the ones verified in [the release publication](6.1.0-beta.1-publication.json).

## Implemented content

Spanish, English and Catalan pages now describe twelve supported feature categories: sight-reading/technique, Hanon warm-up, MIDI/pedals/following, routines, score import/annotations/framing/printing/OCR, quick practice, metronome, saved-history/progress, local multimedia, Calendar/recurrence/reminders, backups/device connection and workspace/language/theme preferences. Recording and the time-chart additions are explicitly marked beta 6.1. Media cloud copies and sharing are deferred; notebook JSON backup/synchronization excludes recordings. The bilingual privacy page describes camera/microphone use, local media and installation identity, with the effective date updated to October 15.

The beta section opens an accessible native dialog with current notes and 26 previous archived versions, newest first. The current notes are localized; existing historical translations are reused and other historical notes retain their original language. Each entry links to its complete maintained source. The dialog scrolls internally, keeps a 44px close control visible, supports Escape and restores focus to the opener. Reopening returns to the current version.

## Screenshots and validation

[35 new captures](../quality-review/captures/website/2026-10-15-beta61-02/capture.json) use the released production web build, disposable notebooks and generated audio tones; no microphone, camera or personal notebook is used. New tablet and landscape-reading views replace the old referenced imagery. Older baseline folders remain intact. Screenshots have fresh image-version URLs and localized alternative text.

[Dialog evidence](../quality-review/captures/website/2026-10-15-beta61-release-notes-03/verification.json) covers Spanish/English/Catalan at phone/tablet portrait/landscape and 320px. Four website checks pass: localized download manifests/links, responsive image decoding/layout, content coverage/asset references and the release-dialog history, scrolling, close, focus and reopening behavior. This is responsive-browser verification, not native-device acceptance or owner visual approval of the new website layout. Public verification is recorded separately after the website deployment.
