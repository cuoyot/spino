# SPino 6.1.0-beta.8 (61)

## Release notes

Fixes the missing Google Drive transfer check in Android beta Profile. The platform check now calls the platform helper correctly, so the test entry is visible and opens the isolated transfer screen. Update both devices, open Profile from the avatar, then select Google Drive transfer check.

Retains beta7 recording-duration and saved-viewer improvements. The Drive check uses only a bundled synthetic recording and your selected Google account; automatic synchronization of personal recordings is not enabled. Google test users must be configured while OAuth remains in testing.

## Validation and delivery

The regression check must navigate the packaged Android app through Profile using disposable namespaced storage, verify the visible entry, and open the transfer screen. Replacement installation preserves the existing notebook. Actual Google consent and physical two-device transfer remain owner acceptance tests. Stable Android, earlier beta APKs and iOS Simulator downloads are retained.
