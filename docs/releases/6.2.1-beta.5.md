# SPino 6.2.1-beta.5

Android versionCode 117. Owner-authorized website beta update based on published beta116. Stable 6.2.0 (112) stays unchanged. No Play submission is part of this APK/website delivery.

## Changes

Continuous expanded calendar weeks, compact horizontally scrolling planned/saved practices and events, real weekly minutes, a current-week heading and floating Today. Library and Progress follow the supplied calendar reference. Add work combines the existing work form and PDF-import entry. Today, Practice and Profile keep their existing presentation; notebook data, stable IDs, original scores and annotations are preserved.

The owner reviewed corrected responsive snapshots and requested APK creation and publication. Production build, 47 focused model/arithmetic checks and 18 selected browser checks pass. Four older scenarios fail at the same steps on an isolated unmodified beta116 source and remain documented separately. Native/package/public verification is recorded in the release validation files.
