# SPino 6.1.0-beta.12 (65)

## Release notes

Backup & sync now shows Google Drive, the connected Google account and notebook explicitly. The old provider-file connection is paused and its connection options are removed. Existing local notebooks, previous cloud files, scores, annotations and merge history are kept when moving to Google Drive. The isolated transfer test is removed.

Use the same Google account on both devices. On the first, connect and select this device’s notebook. On the second, select the existing notebook. Confirm with Connect selected notebook; Cancel closes the selection without moving the notebook. When moving an existing shared connection, matching notebooks retain their identity and combine independent edits.

Saved audio and video recordings are now copied through that notebook’s Google account. Copies retain recording and piece IDs, titles at upload, dates, durations and verified file bytes. Transfers resume after interruption and respect the device’s network preference. Downloaded recordings play offline. Draft recordings and unrelated notebooks are excluded. Deleting a local recording keeps an existing Drive copy and prevents automatic redownload on that device; title changes remain local to each copy. Disconnecting or pausing stops future transfers without deleting local or cloud copies.

Notebook edits upload shortly after saving. Checks for other-device changes run every 30 seconds while SPino is open. Unchanged background checks keep the connection card mounted and preserve its size and controls. Incoming notebook changes and media copies wait for practice/editing to finish.

Local notebook saving, offline practice, JSON export/restore/conversion and local recovery remain available. JSON copies contain the notebook and scores; they do not embed audio/video files.

## Validation and delivery

Synthetic protocol and browser checks cover connection/migration, explicit selection/cancellation, retained IDs/PDFs/annotations, silent unchanged polling, two-device recording copies, interrupted upload recovery, integrity failure, Wi-Fi/offline policy, local deletion, and offline playback. Native packaging, cache readback and original notebook retention are verified separately. Real Google authorization, physical cross-device copying and owner layout acceptance remain separate device checks.
