# SPino 6.1.0-beta.13 (66)

## Release notes

Backup & sync → Manage now offers Disconnect Google account even if notebook setup failed or selection was cancelled. Connect Google Drive then lets you configure the account again. Disconnect keeps the local notebook, recordings and remote files; a paused previous file connection and its merge baseline are retained after failed migration. A connected notebook uses the existing disconnect confirmation.

Drive downloads now verify the metadata revision before and after reading content, with bounded retries if it changes. Uploads keep their conditional revision protection. Setup errors distinguish downloading, uploading and finalizing, and are translated into Spanish and Catalan, including the previous persisted conflict message.

This is a candidate correction for the owner's setup failure on both physical devices. Synthetic checks reproduce a metadata/media validator mismatch, but the exact rejected HTTP operation in those devices remains unconfirmed. Local saving, offline use, scores, annotations, JSON copies and recovery remain available.
