# SPino 6.1.0-beta.22 (75)

## Release notes

Keep the practice currently open on its own device while completed history, scores and annotations synchronize. A phone's unfinished practice no longer competes with the tablet's empty current-session slot after finishing. Incoming updates preserve the local pending checkpoint; running practice, score screens, editing and recording still defer adoption. Full manual JSON backups retain the pending practice. Existing conflicts limited to the old current-session slot recover after a fresh read; genuine overlapping edits still require review.

Drive now shows its synchronization phase and last successful check, with a Pause synchronization action. Silent authorization and bridge requests have bounded waits. Pausing preserves pending work and cancels the request; late replies cannot replace newer changes. Incremental uploads retry safely after uncertain network responses, retaining their allocated identities. Reopening the app can recover transient failures without resuming an explicit pause.

Recording copies accept missing optional Drive checksum metadata while still verifying the actual bytes and rejecting mismatches or foreign identities. Includes lesson completion, teacher recording links, camera controls, audio animations and Android sharing from beta21. Local notebooks, saved practices, PDFs, annotations and original recordings are retained.

## Validation and delivery

Build 75 updates the separate Android beta. Synthetic two-device and browser checks cover a paused phone practice receiving a completed tablet result, legacy active-slot conflict recovery, lost upload responses, DNS failures, pause/retry, stale responses, file integrity and the shared recording flows. Native replacement installation and data retention are recorded separately. Real Google authorization, the exact physical recording metadata error and two-device owner acceptance remain open. Stable Android, Google Play and iOS Simulator downloads remain unchanged.
