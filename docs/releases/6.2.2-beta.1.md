# SPino 6.2.2-beta.1

Android versionCode 122. Owner-authorized APK and website beta, based on published stable 6.2.1 (121). Existing MusicXML, backup/storage, navigation, release notice and stable downloads are retained. No Play submission is requested.

## Changes

Calendar synchronization preserves the visible date and loaded weeks. The practice type precedes its dependent controls; repertoire omits tempo and the lone goal field stays visible. Optional warm-up appears after total duration and borrows minutes from the main blocks. It supports Free, selected Hanon, Reading and selected Scales. Static scale notation is paired with marked piano keys and owner-selected Roman degrees I–VII. Metronome synthesis uses AudioWorklet, the circular marker is centered, and shared clocks use compositor digits.

## Validation

Focused browser and unit checks, signed APK/AAB parity, replacement installation with retained emulator data, native timing and exact website publication are recorded in the release validation/publication manifests. Physical-device audio output remains a separate acceptance step.

The owner follow-up adds a mode-choice step before configuration, consistently across Reading, Technique, Repertoire and Free. MIDI remains an automatically detected piano connection. Native testing also corrects delayed first-click initialization: free clicks anchor to the first actual audio render, and generated clicks skip expired count-in beats rather than playing late.
