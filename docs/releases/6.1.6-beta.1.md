# SPino 6.1.6-beta.1

Android versionCode 107. Website beta APK installs beside stable as `com.miguecoll.spino.beta`.

## Release notes

Verified compressed notebook copies reduce content requests when opening the existing shared notebook on another device. The connection, identifiers, original history and stable-client compatibility are preserved, without migration. Synchronization rotation remains continuous through progress updates and screen changes.

## Implementation and limits

Bounded immutable 2 MiB expanded segments contain existing verified commit and record objects. Each decoded object must match the original hash and current Drive ID, version and size. A bounded scoped index is published after segment verification. Missing or corrupt acceleration falls back to the originals. Older clients ignore distinct auxiliary markers. Verified segments are reused; ordinary polling does not load packs. Score bytes remain on the existing deferred asset path.

This beta does not compact history or delete originals. Acceleration adds files; retention and incremental graph materialization remain separate work. Existing stable 6.1.5 already used parallel reads and an optional single compressed checkpoint; this beta removes that checkpoint's whole-history size bottleneck by using segments.

## Validation

86 focused protocol/indicator tests pass, including exact stable 6.1.5 interoperability, interruption, malformed auxiliary data, changed/missing originals and unchanged polling. Two spinner browser tests pass over synthetic Drive, both themes, four orientations and four shared-header routes. Native replacement-install and broad-suite results are recorded in the validation report. Physical-device Google Drive acceptance remains pending.

Synthetic benchmark with 10,000 note edits: stable 20,003 content reads versus beta 12; total response bytes 20,699,512 versus 17,335,430. Both use one request for an unchanged warm poll. This is not a physical-device timing guarantee. See `6.1.6-beta.1-benchmark.json`.

Existing originals remain available if optional compressed copies are absent.
