# SPino 6.1.0-beta.11 (64)

## Release notes

Fixes a Google Drive notebook connection failing with “Drive did not provide a safe file revision” when opening the shared notebook on another device. Notebook reads and updates now use Drive’s file revision resource, retaining conditional writes that reject simultaneous changes. Existing notebook identities, pending uploads and cloud files are preserved.

Update both devices. On the affected device, open Profile → Backup & sync → Manage and retry the move to Google Drive using the same Google account. Choose the existing notebook when offered. A failed move keeps the previous connection and local notebook; it does not require deleting or recreating the shared file.

Local saving, offline practice, JSON export/restore/conversion and the local recovery copy remain available. Personal recordings remain on the device.

## Validation and delivery

Synthetic checks cover a second device joining without HTTP ETag headers, concurrent edits during download or upload, resuming an incomplete beta10 file without duplication, legacy migration, offline operation and retained local copies. Native request routes remain restricted to Google Drive files. Package, installed-emulator data retention and public delivery are recorded separately. The owner reports beta10 working on the first device and the revision error on the second; the corrected physical two-device flow still requires owner verification.
