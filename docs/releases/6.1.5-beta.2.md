# SPino 6.1.5-beta.2

Android versionCode 101.

## Release notes

Google Drive connection now shows activity, the current step and elapsed time. Notebook comparison shows progress and explains longer waits. Closing the window prevents it from reopening automatically. Includes the previous beta’s synchronization and backup features.

## Limits

Daily backups require the app to be open. Complete ZIP limit: 250 MB. Physical two-device and cellular Drive validation remains pending.
