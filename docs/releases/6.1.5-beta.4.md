# SPino 6.1.5-beta.4

Android versionCode 103.

## Release notes

Backup setup now starts from a visible pending card and uses two guided steps: confirm the notebook folder/name, then activate daily changed backups with the latest seven copies. The existing principal is retained; mobile data is the only optional setup choice. The card remains visible after Later until configuration is complete. Older dismissed notices cannot hide pending setup.

Preparation, file and upload phases show elapsed time and available real progress. Results distinguish a verified copy from a first copy still waiting for Wi-Fi, the principal device, or a failed transfer. Recovery tools are separate from setup; optimization remains automatic. The completed setup card refreshes immediately in the app.

## Limits

Automatic backups require Spino to remain open; complete ZIP limit 250 MB. Physical two-device Google Drive and 5G acceptance remain pending. No personal notebook or Drive file was changed during release testing.
