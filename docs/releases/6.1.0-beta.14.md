# SPino 6.1.0-beta.14 (67)

## Release notes

Notebook synchronization now sends small changed records and separate score pieces instead of rewriting the complete JSON. Editing a note does not resend its PDF. Verified caches and allocated operation IDs survive interruption/restart; retries do not duplicate the same commit. Quiet checks only fetch Drive changes metadata, without uploading or downloading notebook objects. Full JSON remains available for export, restore and recovery; saved audio/video keeps its separate resumable copy system.

Update both Android devices before syncing again. Existing Drive JSON notebooks migrate automatically after a recovery copy and verified new objects. The original file content/name is retained with an archived connection marker; older clients stop writing it. Interrupted migration resumes, and concurrent old-format edits block stale activation. Stable notebook/record IDs, PDFs, annotations and local progress are preserved in synthetic migration checks. Overlapping edits still require review. Keep the new SPino folder intact in Drive.

## Validation and delivery
