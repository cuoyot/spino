# SPino 6.2.4-beta.3

Android versionCode 131. Owner-authorized website beta delivery on 26 November 2026.

## Changes

Add work opens the existing form directly, including optional PDF import and local metadata detection. Calendar Week/Month, Progress sections and Library tabs share a compact 60 px header and 44 px navigation bar. Scrolling removes the small leading space and joins the menu to the header without a divider or shadow. Only the background fades from transparent to the header color during the approach; text and icons remain opaque. Touch targets remain at least 44 px.

Today explicitly returns to the current calendar week instead of restoring the previous scroll anchor. Passive same-range calendar updates retain their existing position.

## Validation and distribution

Synthetic responsive evidence covers the unified work form, manual/PDF saving and failure retry, both themes and phone/tablet orientations, shared navigation, keyboard activation, Today, and progressive background coverage in both directions. Production/package signatures, identical web assets, Android unit checks, replacement installation/data retention/foreground and exact-commit public checks are recorded in the validation/publication manifests. Existing unrelated broad-suite debt and physical-device acceptance remain separate.

Distribution is the website beta channel. Stable 6.2.3/build128 and its published App Store link are retained. No production Play rollout is requested. The next review session continues with the remaining interface audit proposals and owner feedback on this beta.
