# SPino 6.1.6-beta.5

Android versionCode 111. Website beta updates com.miguecoll.spino.beta. The signed production-identity AAB is supplied for handoff; this beta delivery retains the stable Google Play rollout and stable 6.1.5 (106) website downloads.

## Changes

After Android confirms a manual ZIP write, Backups shows Backup saved and Prepare a new copy. Reopening no longer presents the completed archive as waiting for a destination. Cancelling retains the prepared archive; retry after failure does not repeat preparation. A browser-triggered download does not claim a provider-confirmed save.

The tinted nested card becomes an inline status. Ready dialog actions stack with spacing, and preparation/ready dialogs use the existing top Close as their single dismissal action. Initial progress and errors also render before an archive date exists.

## Validation and limits

Production web build and 19 focused tests passed during review, including cancellation, acknowledged save, fresh-copy preparation and existing synchronization/settings behavior. Four-layout responsive evidence uses a disposable synthetic notebook. Native packaging, replacement installation and publication results are recorded separately. Personal ZIP completeness remains a later owner check; no personal archive was read. Concurrent backup-settings changes are excluded from this release.
