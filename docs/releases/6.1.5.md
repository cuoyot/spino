# SPino 6.1.5 (106) — Drive synchronization and verified recording recovery

## Release notes

Backup setup waits for synchronization and prevents concurrent operations. Notebook name, folder and reference remain consistent across devices. Supports MP3 and compatible audio aliases. Incorrect Drive format labels are repaired only after verifying the original recording and remote bytes. ZIP errors identify the affected recording.

Promotes 6.1.5-beta.6, including metadata-first synchronization, guided backup setup, complete ZIP export, coherent notebook identity and byte-verified recording MIME recovery through private Drive appProperties.

## Validation limits

Physical two-device Google Drive and cellular acceptance remain unverified. Notebook IDs, history, scores, annotations and recording bytes remain preserved. Automatic backups require the app to be open; ZIP limit 250 MB.
