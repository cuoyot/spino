# SPino 6.2.2

Android versionCode 123. Owner-authorized production promotion of beta122, retaining the same practice-mode, warm-up, scale preview, calendar-position and audio-clock changes. The owner asks that users of the previous stable release receive this update. Production submission and actual Google Play availability must be verified directly.

## Changes

Choose Mobile or With piano before configuring Reading, Technique, Repertoire or Free practice. Connected MIDI is detected at physical-practice start/reopen. Optional warm-up borrows minutes from the selected total. Scale previews show marked piano keys, note names and Roman degrees I–VII. Calendar synchronization keeps the visible date, and AudioWorklet metronomes include precise first-click initialization. Shared clocks and centered beat indicators are retained. Notebook data, IDs, scores and annotations remain intact.

No new permissions or developer data collection are introduced.
