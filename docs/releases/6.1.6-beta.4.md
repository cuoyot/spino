# SPino 6.1.6-beta.4

Android versionCode 110. Website beta APK updates `com.miguecoll.spino.beta`. Signed AAB for `com.miguecoll.spino` is supplied in the handoff; this website beta delivery does not change the stable Play rollout. Stable 6.1.5 (106) remains available.

## Changes

Sync & backups groups notebook and multimedia under Cloud synchronization, and ZIP save, restore and automatic settings under Backups. Recordings follow the first eligible notebook check using the existing Wi-Fi/mobile-data preference. Errors retain retry/repair controls.

Automatic backups have direct enable/disable settings, explicit principal-device takeover and local disk as the default for new configurations. Android 10+ uses Downloads / SPino backups in a notebook-specific folder. ZIP names use the notebook name and timestamp. The main row shows the last completed copy and folder, with Prepare ZIP / Save progress during execution. Only the latest seven completed archives are retained after verified commit.

Drive backups explicitly connect their own Google account. Credentials and binary transport are isolated from notebook synchronization, including when the same account is selected. Enter a folder name instead of choosing from existing folders. A name matching the notebook or its folder is blocked with a suggested `_backup` alternative. Closing an unsaved account choice preserves the active configuration. Existing remote backup configurations require this explicit connection before writing another ZIP; original archives and the notebook connection remain intact.

Manual ZIP save uses Android's file destination picker and confirms completion after the output stream closes. Cancellation retains the prepared ZIP for retry. JSON export/import is visible in Manage and explicitly excludes multimedia; complete ZIP backups include linked recordings and scores.

## Validation and limits

The owner accepted the responsive layout on 26 October 2026. Synthetic browser and native emulator validation are recorded separately from physical Google consent/provider acceptance. Final release package signatures, packaged web assets, replacement installation and retained IndexedDB files are recorded in the validation report. Automatic checks require SPino to be open; the complete archive limit remains 250 MB. Shared principal coordination still uses the connected notebook. No notebook migration or reconnect is required.
