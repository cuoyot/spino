# SPino 6.1.0-beta.1 (54)

First Android beta of the 6.1 series, requested by the owner on October 15, 2026.

## Release notes

Record audio or video while practising a repertoire piece. Review, name and save each take, then play it from the piece or Library → Multimedia. Recordings stay on the current installation; notebook backup and synchronization do not include the media. Cloud copies and sharing are deferred.

The floating score Record button becomes Stop during capture. The capture panel stays hidden while reading the score; stopping opens the review. Pausing practice keeps the score visible. Edit replaces the pencil with a checkmark in the same position. The paused clock remains visible and disabled while editing, with the toolbar anchored in place.

Progress includes a 12-week practice-time chart and detailed date ranges with combinable practice-type and repertoire-piece filters. Comparison uses the preceding equal-length period; exact values remain accessible.

## Validation and delivery

Release validation, artifact hashes, emulator replacement-install evidence and public download verification are recorded in the adjacent release manifests. Browser recording tests use synthetic audio/video and disposable notebooks. Native installation does not establish physical camera/microphone or provider acceptance.

The Android beta package remains `com.miguecoll.spino.beta`, compatible with replacement installation of the existing beta. Stable Android 6.0.0/build53 and the iOS Simulator beta9/build48 remain separate downloads. No Google Play or TestFlight publication is part of this release.
