# SPino 6.0.0-beta.1 (40)

Release date: 2026-10-12. Major beta channel. Stable remains **5.2.3 (35)**, identified by the owner on this date, available on [Google Play](https://play.google.com/store/apps/details?id=com.miguecoll.spino). Previous test APKs are historical, not the stable store release.

## Changes

- Custom iOS Capacitor bridge using Apple Core MIDI: input discovery/hot-plug, MIDI note and pedal events, running status and fragmented packets, and the Apple Bluetooth MIDI connection panel. Physical USB/BLE acceptance is open.
- Official Capacitor local notifications on iOS, with persistent OS scheduling, explicit permission requests, ownership-safe updates, stable reminder IDs, and a conservative pending-notification limit. Android's native alarms and boot/package-update restoration were reviewed. Closed-app delivery acceptance is tracked below.
- Light, dark and device-synchronized themes from Profile. Existing notebooks retain dark; new notebooks default to system. The notebook format and record IDs are unchanged.
- Rate app and native sharing actions. iOS requests Apple's in-app review; display is controlled by Apple. Android opens the stable Play listing. Sharing includes only the public app URL.
- Initial six-screen walkthrough with Skip, Back, Next and Finish; replay from Profile, device-local completion and restoration of the original screen.
- Warm-up guide focuses its introductory heading and resets the dialog/content scroll to the start.
- Includes previously selected iOS date/time, landscape safe-area and unrestricted network-type fixes.

## Distribution

Android: `spino-6.0.0-beta.1-40-android.apk`, debug-signed beta, application ID `com.miguecoll.spino.beta`, display name SPino Beta. It coexists with stable and earlier `.test` builds; no existing notebook is automatically transferred. Use the application's backup/import flow if you choose to copy a notebook.

iOS: `spino-6.0.0-beta.1-40-ios-simulator.zip`, unsigned simulator app for Mac/Xcode. It is **not an IPA**, cannot install on a physical iPhone/iPad and cannot be uploaded to TestFlight. The owner has no Apple Developer account; signed-device distribution remains unavailable. The public archive contains the production app, never the audit driver.

To use the iOS archive: unzip it, start an iOS simulator in Xcode/Device Hub, then run `xcrun simctl install booted /absolute/path/App.app` and `xcrun simctl launch booted com.miguecoll.spino`. The simulator must support iOS 15 or newer and match one of the included architectures.

The website separates stable and beta in Spanish, English and Catalan. Downloads and checksums are listed in `6.0.0-beta.1-artifacts.json`.

## Verification and limits

- Web production build passed.
- Non-browser regression: 175 passed, zero failures, one skipped.
- Focused beta/walkthrough/theme and iOS safe-area browser checks passed. Six main screens captured in both themes across phone/tablet portrait/landscape. These are responsive-browser evidence, not native acceptance.
- Native Core MIDI parser checks passed (running status, fragmentation, real-time messages, note-on velocity zero, pedals and independent sources).
- iOS Simulator and Android debug compilation passed. All 256 final web files are identical in `dist`, the APK and the production iOS app. Android requires Java 21; official Temurin 21 is installed in the user JavaVirtualMachines directory for future builds.
- Native iPhone and iPad warm-up portrait and landscape evidence: focus H2; all dialog content starts at scrollTop 0; no horizontal overflow. Evidence: `docs/quality-review/captures/beta/2026-10-12/native-warmup` and `native-warmup-tablet`.
- Physical MIDI/BLE, printer, keyboard and Android PDF acceptance remain for device/owner testing; the owner's PDF/printing scope was preserved.
- Notification delivery with the app terminated and final Android emulator foreground checks are recorded in the handoff status below. Build success alone is not delivery acceptance.
