# SPino 6.1.5-beta.3

Android versionCode 102.

## Release notes

Notebook history and settings synchronize before score downloads. Updated clients can use a verified compressed metadata checkpoint while retaining compatibility with existing incremental clients. Bounded parallel reads, safe read retries and elapsed-time feedback reduce silent waits. Scores remain visible and can be downloaded on demand with mobile data.

Connection setup includes a default folder, an explicit choice for existing local data, and verified complete local recovery before opening a remote notebook without merging. Legacy conversion requires confirmation that every device has been updated and synchronized. Verified migration redirects reconnect updated devices. Storage controls separate daily complete backups from notebook synchronization and expose safe device reset with a retained complete archive.

## Limits

Automatic backups require Spino to be open; only the principal device creates one changed snapshot per day, retaining seven verified archives. Complete ZIP limit: 250 MB. A first connection without a compressed checkpoint still reads the metadata graph. Real two-device Google Drive and physical cellular validation remain pending. Already-installed old apps cannot acquire a new migration detector; update all devices before converting. No personal Drive file was migrated during this release work.
