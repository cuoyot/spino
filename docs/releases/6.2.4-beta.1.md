# SPino 6.2.4-beta.1

Android versionCode 129. Website beta requested on 20 November 2026, based on published stable 6.2.3 (128).

## Changes

The practice clock keeps the correct elapsed time after an interface delay, without counting the interval twice or jumping back. Improves pausing and resuming in free practice, exercises, PDF and MusicXML scores.

## Validation

Visible-digit long-task, pause/resume and minute-width regressions cover the shared clock. Package signatures, embedded web assets, Android replacement installation and exact-commit website publication are recorded in the release manifests. Native launch is separate from physical-device timing acceptance. This delivery targets the website; no Play Console submission is claimed.
