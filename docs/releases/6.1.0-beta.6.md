# SPino 6.1.0-beta.6 (59)

## Release notes

Fixes a valid notebook being rejected as invalid or incompatible during synchronization or backup restore when its reader settings use Catalan. The reader supported Catalan, but the backup validator used an older language list. Validation now uses the same supported-language registry as the reader.

Update both devices, then choose Try again on the existing cloud connection. Notebook format 1 and organized manual backups remain supported; stable record IDs, history, score files and annotations are preserved. Unknown languages, future formats and malformed data still fail validation before any incoming data is applied.

Device linking now offers only Scan a notebook QR and Select an existing cloud file. Manual connection-code entry remains available from the scanner as a camera fallback. The connected notebook's QR moves to Backup & sync → Manage → Show my notebook QR. An existing cloud connection, including a paused one, must be disconnected explicitly before joining, creating or selecting a different notebook; regranting access to the same notebook remains available for provider recovery. Local/cloud files are retained on disconnect. Connection setup errors stay visible in Manage instead of being lost behind the independent-backup state.

Catalan cloud settings also translate the update-failed heading and automatic-update explanation that previously appeared in English.

## Validation and delivery

The exact rejection was reproduced before the fix. Supported reader languages round-trip through both backup formats. Two simulated devices use the production validator to exchange a Catalan notebook, retain independent history and preserve score/annotation identities. Browser checks cover the real store/export/sync path, local continuation and refusal of invalid remote data. Synthetic evidence is separate from physical-device/provider acceptance. Final package/signature, replacement install, focused checks and public delivery are recorded in adjacent manifests.

Stable Android 6.0.0/build53, previous beta5 and iOS Simulator beta9/build48 retain their artifacts. No Google Play or TestFlight upload is included.
