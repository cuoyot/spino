# SPino 6.1.4-beta.7 (98) — Event calendar picker

Replace the native event date input with an inline calendar for creation, editing and optional recurrence end dates. Preserve local date strings, event IDs and notebook data. Browser regressions cover leap days, recurrence limits, editing, persistence and phone/tablet widths. Includes beta 6 MIDI timing and MIDI/WAV/MP3 sharing. Website beta delivery only.
