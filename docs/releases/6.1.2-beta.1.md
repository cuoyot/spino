# SPino 6.1.2-beta.1 (87) — Drive notebook recovery

## Release notes

Rename the connected Drive notebook without changing its identity or stored practice. Compare same-name notebooks by saved sessions, practice this week, latest practice date, work count, weekly target and sessions absent from the other listed copies. Multiple choices no longer preselect the first notebook. New QR codes include the exact Drive file identity; older readers can still use the notebook name and logical identity.

First connection and explicit synchronization inventory existing immutable notebook records, recovering changes missing from the incremental feed. Local JSON exports identify beta/stable, app version and timestamp, and explain that installed channels keep separate notebooks. JSON preserves practice history, scores and annotations; audio/video files remain separate.

## Delivery

Beta APK updates `com.miguecoll.spino.beta` with its existing signing certificate. Signed AAB retains `com.miguecoll.spino` and is a handoff artifact only; Google Play stable remains 6.1.1 (86). Website publication is explicitly authorized. The original tablet's real Drive state has not been read; synthetic regressions demonstrate the corrected failure mode, not a confirmed diagnosis of the owner's duplicated files. Unsupported remote recording metadata remains a separate issue; this release does not rewrite personal recordings.
