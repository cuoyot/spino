# SPino 6.0.0-beta.13 (52)

Owner-requested Android beta publication for testing, October 15, 2026. Synchronization failures now offer Continue locally from the pre-practice check, cloud overview and Manage connection. The pause persists across restart and retains notebook IDs, local edits, PDFs, annotations, cloud file and merge history. A stalled provider can be left immediately without allowing a late response to replace local work. Quick practice enters once after choosing local mode.

Android distinguishes missing provider, revoked permission and unavailable file from transient read failures. JavaScript also recognizes the older generic `No content provider` diagnostic. Permanent access failures stop automatic retries and expose selection of the same notebook file. Identity checking and baseline retention preserve local deletions and independent changes after reconnect; overlapping edits still require review. No notebook schema or IDs change.

The regression suite now follows previously accepted flows: Profile in the persistent header, saved practice returning Today, direct score entry, portable backup format selection, current practice catalogue defaults and controls reachable by scrolling. Existing snapshots are protected by running the complete suite in an isolated temporary copy. No new visual redesign is part of this beta.
