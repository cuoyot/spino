# SPino Google Play screenshot pack

Prepared from SPino 6.0.0-beta.13 on October 15, 2026. Actual production UI with disposable synthetic notebooks. No personal data, simulated MIDI connection, external advertising copy or device frame. These are responsive browser captures of the shipped web UI, not native-device acceptance evidence. Recheck them against the final Android build before the definitive Play release if the UI changes.

Start with `upload/<language>/<device>/`: eight selected screenshots per device, combining four light and four dark screens. Languages: Spanish (`es`) and English (`en`). Devices: phone, 7-inch tablet portrait and 10-inch tablet landscape. The `es/light`, `es/dark`, `en/light` and `en/dark` folders retain all 96 original alternatives. `index.html` previews those alternatives. `alt-text.csv` supplies short localized descriptions for the selected files.

All PNGs are opaque 24-bit RGB, 1080×1920 portrait or 1920×1080 landscape. Dimensions, format, aspect ratio and SHA-256 were checked during capture. Use the language/device folders separately in Play Console; each selected folder stays within the eight-image limit.

Google guidance checked October 15, 2026: https://support.google.com/googleplay/android-developer/answer/9866151?hl=en . This pack uses the recommended 9:16 or 16:9 dimensions and shows the actual app interface. Store submission and final release have not been performed.
